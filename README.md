# AvnishRaj_1024170125_UCS420

Python solutions for UCS420 assignments.

## Structure

- `Assignment 1/assignment_1_numpy.py` - NumPy questions in order.
- `Assignment 2/adventure_works_preprocessing.py` - Adventure Works preprocessing, transformation, similarity, and correlation analysis.
- `Assignment 3/assignment_3_pandas.py` - Pandas questions in order.

## Run

```bash
python3 "Assignment 1/assignment_1_numpy.py"
python3 "Assignment 2/adventure_works_preprocessing.py"
python3 "Assignment 3/assignment_3_pandas.py"
```

For Assignment 2, place the Kaggle Adventure Works customer CSV in `Assignment 2/`, or pass its path:

```bash
python3 "Assignment 2/adventure_works_preprocessing.py" path/to/AWCustomers.csv
```
